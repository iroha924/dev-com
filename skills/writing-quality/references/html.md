# HTML の文章と資料

社内外の説明資料や報告を HTML で受け取ったときの確かめ方。**機械の検査は無い**（検査スクリプトは HTML を
終了コード 2 で止める）。マークアップを自前で解釈して数えると数え落とすので、内容は読んで判定する。

## 本文として読む

ソースのタグではなく、読み手に見える本文として読む。見るもの:

| 要素 | 見ること |
|---|---|
| `title`、`h1`〜`h6` | 見出しの並びが、読み手の知りたい順になっているか。テンプレートや場面の型（Q8）と合うか |
| `p`、`li` | 本文。共通の評価基準（Q1〜Q7）で判定する |
| `table`、`caption`、`th` | 表の数値と、本文の主張が一致するか（Q6） |
| `img` の `alt`、`figure`、`figcaption` | 図の短い説明と長い説明があるか、本文と一致するか（[figures.md](figures.md)） |
| `a` | リンク先が本文の説明と合っているか。確かめていなければ未検証 |

本文を取り出すときは、ファイルを読んで目で追えば足りる。長いときに道具を使うなら、ブラウザの「テキストのコピー」や
既存のコマンドを使い、取り出した本文と元の HTML の両方を見て、抜けた部分が無いかを確かめる。

## 表示の確認

描画して、見え方・図・表の崩れを見る。ブラウザで開ける道具（ブラウザを操作できるツール、スクリーンショット）が
あるときだけ行い、無ければ **表示の確認は未検証** と書く。ソースを読んだだけで「表示に問題なし」と書かない。

画像ファイルが手元に無い（`src` の先が無い）ときは、図の中身は確かめられない。`alt` と本文と表だけで判定し、図の中身は未検証と書く。
